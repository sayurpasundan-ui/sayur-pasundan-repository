# Panduan aset homepage

Homepage menggunakan aset yang disediakan, dioptimalkan ke WebP, dan disimpan di `public/assets/images/brand/`.

## Susunan homepage
1. Header dengan logo aplikasi, pencarian, navigasi, dan keranjang.
2. Slider empat banner: jadwal pengiriman, customer service, gratis ongkir, dan catatan pengiriman.
3. Grid enam kategori yang dapat dipilih untuk memfilter katalog saat kategori tersedia di D1.
4. Bagian keunggulan memakai lima aset ikon/ilustrasi.
5. Banner ajakan belanja dengan background brand.
6. Katalog produk dari API D1, keranjang, checkout, dan akses chat melalui konfigurasi nomor WhatsApp.

## Mengganti gambar
Ganti berkas di `public/assets/images/brand/` sambil mempertahankan nama berkasnya. Untuk banner, ubah versi desktop dan mobile sekaligus. Versi banner saat ini sudah berisi teks di dalam gambar; perubahan teks perlu dilakukan pada file desain sumber sebelum mengekspor ulang gambar.

## Status Admin Panel
Logo sudah dipakai konsisten pada website pelanggan dan Admin Panel. Admin Panel yang ada tetap mengelola produk, varian, satuan/harga, foto produk, dan pesanan. Editor visual untuk mengganti banner, background, dan keterangan homepage langsung dari Admin Panel belum dibuat dalam perubahan ini; aset homepage masih merupakan berkas statis repository. Ini dapat dijadikan tahap berikutnya jika diperlukan.
