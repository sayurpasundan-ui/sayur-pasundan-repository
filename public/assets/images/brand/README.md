# Aset Brand Sayur Pasundan

Semua gambar berikut berasal dari aset yang diberikan pemilik dan dikonversi ke WebP agar lebih ringan. File asli tidak dimodifikasi.

- `logo-sayur-pasundan.webp` — wordmark utama situs/header/footer.
- `logo-aplikasi.webp` — ikon aplikasi.
- `background-cream.webp` — latar section ajakan belanja.
- `hero-jadwal-desktop.webp` / `hero-jadwal-mobile.webp` — banner jadwal pengiriman.
- `hero-customer-service-desktop.webp` / `hero-customer-service-mobile.webp` — banner customer service.
- `hero-gratis-ongkir-desktop.webp` / `hero-gratis-ongkir-mobile.webp` — banner gratis ongkir.
- `hero-catatan-desktop.webp` / `hero-catatan-mobile.webp` — banner catatan pengiriman.
- `kategori-sayuran.webp`, `kategori-buah.webp`, `kategori-bumbu-rempah.webp`, `kategori-perlengkapan-dapur.webp`, `kategori-lauk-pauk.webp`, `kategori-groceries.webp` — ikon kategori.
- `keunggulan-antar-rumah.webp`, `keunggulan-proses-cepat.webp`, `keunggulan-pilihan-kualitas.webp`, `keunggulan-praktis-hemat.webp`, `keunggulan-garansi-retur.webp` — gambar keunggulan.

## Catatan penting

Banner desktop memakai rasio 2:1; banner mobile memakai file rasio 4:3 yang disediakan pemilik agar teks banner tidak terpotong. Gambar kategori boleh menjadi fallback visual kartu produk saat foto belum tersedia, tetapi **jangan menyimpan gambar kategori sebagai foto asli produk**.
